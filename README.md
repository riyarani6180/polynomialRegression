# Polynomial Regression

## Project Overview

This project demonstrates the implementation of Polynomial Regression using Python and machine learning techniques.

Polynomial Regression is a supervised learning algorithm used to model the relationship between an independent variable and a dependent variable when the relationship is non-linear. Unlike Simple Linear Regression, which fits a straight line to the data, Polynomial Regression can fit a curved relationship by introducing polynomial terms of the input feature.

The project focuses on understanding the implementation, training, prediction, and evaluation of a Polynomial Regression model.

## Objective

The main objective of this project is to:

* Understand the concept of Polynomial Regression.
* Transform linear features into polynomial features.
* Train a regression model on the transformed data.
* Predict the target variable.
* Evaluate the performance of the model.
* Visualize the relationship between actual data and the polynomial regression curve.

## Dataset

The dataset used for this project contains an independent variable and a dependent variable.

The independent variable is used as the input to the model, while the dependent variable is the value that the model attempts to predict.

Example structure:

| Feature | Description          |
| ------- | -------------------- |
| X       | Independent variable |
| Y       | Dependent variable   |

## Polynomial Regression

Polynomial Regression extends Linear Regression by adding powers of the input variable.
